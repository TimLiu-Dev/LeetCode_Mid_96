# Mission: Mid-Tech LeetCode 96 — Masterclass Curriculum (96 Problems)

## Why
Master the definitive 96 algorithm and data structure problems that span the entire spectrum of mid-level to senior technical software engineering interviews at mid-tech (Target, Schwab, McDonald's, Capital One, Fetch, Tinder, Expedia) and top-tier product tech/FAANG (Amazon, Uber, Stripe). The goal is to build visceral mental models, articulate space-time trade-offs instantly, and produce clean, idiomatic production code in Kotlin, Java, and Python.

## The 4 Curriculum Passes & Target Milestones
1. **Pass 1: The 🟢 Foundation Easy (#1–#22)** — 22 Problems: Anchor core algorithmic instincts (Two Pointers, Sliding Window, Prefix Sum, Stack, Linked List, Binary Search, Trees, DP, Bits).
2. **Pass 2A: The 🟡 Core Medium Templates (#23–#57)** — 35 Problems: Master canonical interview templates (BFS/DFS, Tries, Heaps, Intervals, Backtracking, 2D Grid, Knapsack DP). Unlocks Charles Schwab, McDonald's, and Target screens.
3. **Pass 2B: The 🟠 Stretch Medium Variations (#58–#89)** — 32 Problems: Complex pattern combination, topological sorting, Union-Find, Dijkstra, and progressive OOP systems. Unlocks Capital One, Fetch Rewards, Tinder, Expedia, and Amazon SDE I/II.
4. **Pass 3: The 🔴 High-ROI Hards (#90–#96)** — 7 Problems: The essential high-frequency hard problems asked in Upper Mid-Tech and Early Big Tech loops.

## Success looks like
- Solving problems cold on paper/whiteboard within 15–25 minutes each.
- Flawlessly articulating the 4-phase interview script: constraints inquiry, space-time pitch, idiomatic coding, and edge-case dry running.
- Writing idiomatic, zero-waste code in Kotlin, Java, and Python with complete mastery of language runtime memory nuances.
- Successfully passing spaced-repetition cold recall checks at 48-hour intervals.

## Constraints
- 100% self-contained standalone HTML lesson files (Tailwind CSS CDN + vanilla JS, zero external server dependencies).
- Dark-mode, high-polish visual aesthetic (Tufte-meets-Pocock style).
- No corner-cutting or truncation: comprehensive masterclass depth per lesson.

## Out of scope
- Niche competitive programming algorithms with low interview ROI (e.g., Fenwick Trees, Treaps, Aho-Corasick).
- Blind copy-pasting without variable trace and mental model comprehension.
