# RESOURCES: Core Algorithmic & Interview References

## Foundational Algorithm Texts
- **Introduction to Algorithms (CLRS)**, Cormen, Leiserson, Rivest, Stein — Canonical reference for asymptotic analysis, hash tables, trees, and dynamic programming.
- **Algorithms, 4th Edition**, Robert Sedgewick & Kevin Wayne — Deep dive on data structures, priority queues, binary search trees, and graphs.

## Language References
- **Kotlin Standard Library Documentation**: Collections, inline functions, and primitive array optimizations (`IntArray` vs `Array<Int>`).
- **Java Platform, Standard Edition Documentation (Oracle)**: `java.util.Collections`, `HashSet`, `HashMap` collision resolution (buckets to red-black tree), boxing/unboxing overhead.
- **Python Data Model & Built-in Types (docs.python.org)**: Hash table implementation, dictionary amortized $O(1)$ mechanics, `collections.deque`.

## Curated Problem Sets
- **LeetCode Official Curated 75 / Grind 75 / NeetCode 150**: Baseline pattern distribution mapped to the 22 Foundation problems.
